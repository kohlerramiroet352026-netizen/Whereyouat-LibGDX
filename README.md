# Where you at (LibGDX Edition)

Un juego sandbox procedimental 2D desarrollado con **LibGDX** y **LWJGL 3**.

## Características
- Generación de mundos procedimentales por biomas y capas de elevación.
- Ciclo de día y noche con iluminación dinámica.
- Sistema de guardado y carga de partidas persistentes en disco.
- Menús animados, música ambiental dinámica y efectos de sonido.
- Soporte para pantalla completa (F11) y captura del mapa completo (F12).

## Requisitos
- Java 17 o superior (compatible con Java 21).

## Compilación y Ejecución
Para ejecutar el juego usando Gradle Wrapper:
```bash
./gradlew lwjgl3:run
```
En Windows:
```cmd
gradlew.bat lwjgl3:run
```
O ejecutando `run.bat`.

Para compilar el proyecto:
```cmd
gradlew.bat build
```
